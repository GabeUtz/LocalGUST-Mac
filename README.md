# LocalGUST-Mac


A very simple way to run `GUST-Lite.html` locally with COOP/COEP headers using Python.

- Hosts GUST on your PC using a lightweight Python server
- Automatically sets up Cross Origin policies (fixes stuff)

## How to Run

1. Place `GUST-Lite.html` in this folder.

2. Run:
```bash
python3 server.py

3. Go to this url in your browser:
http://localhost:8080/GUST-Lite.html

## Requirements

- Python 3 (Most MacOS laptops come with this preinstalled)
- Port 8080 must be free
